# PDF Brief Generator

Generate professional, well-formatted PDF documents for the operator's review pipeline.

## When to Use

- Compiling venture launch pipeline outputs into a single PDF brief
- Creating operator action documents
- Generating strategic briefs, niche analyses, or financial summaries
- Any time a deliverable needs to go to `for-review/` as a PDF

## How to Generate

Use Python `reportlab` via the `py` command. Never use `python` — always `py`.

### Standard Template

Every PDF brief must include:
1. **Header** — "AI Business OS" branding, document title, date, venture name (if applicable)
2. **Table of Contents** — section list with page numbers (for documents > 3 pages)
3. **Body sections** — one per source (advisor, researcher, analyst, designer, writer, quality-checker)
4. **Footer** — page numbers, "Generated by AI Business OS"

### Page Layout

- **Page size:** A4 (595 x 842 points)
- **Margins:** 60pt top, 50pt sides, 50pt bottom
- **Font:** Helvetica family (built into reportlab, no external fonts needed)
  - Title: Helvetica-Bold 18pt
  - Section headers: Helvetica-Bold 14pt
  - Subsection headers: Helvetica-Bold 11pt
  - Body text: Helvetica 10pt
  - Captions/metadata: Helvetica 8pt, grey
- **Colours:**
  - Header bar: #1a1a2e (dark navy)
  - Accent: #00d2ff (match dashboard accent)
  - Section dividers: #e0e0e0

### Code Pattern

```python
py -c "
from reportlab.lib.pagesizes import A4
from reportlab.lib.units import mm
from reportlab.lib.colors import HexColor
from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer, Table, TableStyle, PageBreak
from reportlab.lib.styles import getSampleStyleSheet, ParagraphStyle
from reportlab.lib.enums import TA_LEFT, TA_CENTER

doc = SimpleDocTemplate(
    r'OUTPUT_PATH',
    pagesize=A4,
    topMargin=60, bottomMargin=50, leftMargin=50, rightMargin=50
)

styles = getSampleStyleSheet()
# Add custom styles as needed
title_style = ParagraphStyle('BriefTitle', parent=styles['Title'], fontSize=18, textColor=HexColor('#1a1a2e'))
heading_style = ParagraphStyle('BriefHeading', parent=styles['Heading2'], fontSize=14, textColor=HexColor('#1a1a2e'), spaceAfter=8)
body_style = ParagraphStyle('BriefBody', parent=styles['Normal'], fontSize=10, leading=14, spaceAfter=6)

elements = []
# Build document content here
elements.append(Paragraph('DOCUMENT TITLE', title_style))
elements.append(Spacer(1, 12))
# ... add sections ...

doc.build(elements)
print('PDF created successfully')
"
```

### Data Tables

For financial data, unit economics, or comparison tables:
```python
table_data = [
    ['Metric', 'Value', 'Notes'],
    ['Revenue per unit', '$24.99', 'After Etsy fees'],
    ['Cost per unit', '$12.50', 'Production + shipping'],
    ['Margin', '$12.49', '50% margin'],
]
table = Table(table_data, colWidths=[150, 100, 200])
table.setStyle(TableStyle([
    ('BACKGROUND', (0, 0), (-1, 0), HexColor('#1a1a2e')),
    ('TEXTCOLOR', (0, 0), (-1, 0), HexColor('#ffffff')),
    ('FONTNAME', (0, 0), (-1, 0), 'Helvetica-Bold'),
    ('FONTSIZE', (0, 0), (-1, -1), 9),
    ('GRID', (0, 0), (-1, -1), 0.5, HexColor('#e0e0e0')),
    ('ROWBACKGROUNDS', (0, 1), (-1, -1), [HexColor('#ffffff'), HexColor('#f8f8fc')]),
    ('PADDING', (0, 0), (-1, -1), 8),
]))
```

### Embedding Images

For design screenshots or charts:
```python
from reportlab.platypus import Image
img = Image(r'PATH_TO_IMAGE', width=400, height=300)
img.hAlign = 'CENTER'
elements.append(img)
```

## Output Rules

- Save PDF to the path specified in the task (usually `for-review/TYPE-name-YYYY-MM-DD.pdf`)
- Keep briefs under 10 pages — this is a brief, not a book
- Always include the date in the filename
- Use the type prefix from config/delivery.md (e.g., NICHE-BRIEF-, OPERATOR-ACTION-, STRATEGIC-BRIEF-)

## Quality Checklist

Before saving the PDF:
- [ ] Document title is clear and descriptive
- [ ] Date is included in header
- [ ] All sections have proper headings
- [ ] Tables are readable (not too wide for A4)
- [ ] Images are appropriately sized
- [ ] Page numbers are present in footer
- [ ] No placeholder text remains
