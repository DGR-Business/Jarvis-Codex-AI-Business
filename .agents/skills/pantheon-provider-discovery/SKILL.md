# Pantheon Provider Discovery

- Start from a provider-neutral Capability Requirement.
- Treat owner or agent suggestions as candidates, not pre-approval.
- Use current official documentation and date the evidence.
- Compare meaningful alternatives where they exist.
- Assess API, SDK, OpenAPI, MCP and browser fallback feasibility.
- Assess cost, quality, latency, reliability, commercial rights, privacy, retention, security, region, support, lock-in and maintenance.
- Benchmark shortlisted providers on the same task where practical.
- Create a Provider Decision Record with recommendation, fallback, unknowns, review date and rollback.
- Do not install packages/MCP servers, grant credentials, accept terms, subscribe, spend or expose Pantheon data during discovery.
