# Plan Amendment Prompt

```text
Evaluate the proposed Pantheon v2.1.1 plan amendment: [describe].

Do not implement it. Compare the proposal with the Master Plan, current Phase
Execution Pack, repository state, commercial priorities and existing ADRs.
Assess evidence, alternatives, migration cost, provider lock-in, security,
maintainability, owner visibility and effect on commercial viability.

Produce a proposed ADR and exact Master Plan/Phase Pack changes, or recommend
rejection. Stop for owner approval.
```
