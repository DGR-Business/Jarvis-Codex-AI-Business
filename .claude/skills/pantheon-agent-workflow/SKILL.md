# Pantheon Agent Workflow

- Define mission, owned/excluded decisions, context, tools, output schema, evidence, escalation, cost and limits.
- Keep authority deterministic.
- Use structured inputs/outputs and bounded loops.
- Prefer explicit workflow state over conversational swarms.
- Add evals for happy path, missing evidence, forbidden actions, approvals, cost and observed regressions.
- Exercise the real agent path and record trace/evidence behaviour.
